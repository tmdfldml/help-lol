## 알려진 제한

- 서명되지 않은 빌드에는 Windows SmartScreen 경고가 표시될 수 있습니다.
- 앱 자체 자동 업데이트는 아직 제공하지 않습니다. 새 설치 파일을 다시 실행해 업그레이드합니다.

## 설치 및 업그레이드

1. 실행 중인 LoL Match Info를 종료합니다.
2. `LoLMatchInfo-<version>-win-x64-setup.exe`를 실행합니다.
3. 기존 버전 위에 설치하면 사용자 설정, 로그 및 내려받은 통계 데이터가 보존됩니다.

## 문제 보고

- 로그: `%LocalAppData%\LoLMatchInfo\Logs`
- 보고 시 앱 버전, Windows 버전, 발생 시각과 재현 절차를 포함하세요.
- 로그에 개인 식별 정보가 없는지 확인한 뒤 필요한 파일만 공유하세요.
