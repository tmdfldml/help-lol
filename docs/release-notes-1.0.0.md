# LoL Match Info 1.0.0

League of Legends 정글 유저를 위한 Windows x64 앱의 첫 정식 1.0 릴리스입니다.

## 주요 기능

- 게임 시작을 자동 감지하고 TOP/JUNGLE/MID/ADC/SUPPORT 5역할 매치업을 표시합니다.
- 승리, 레벨 2·3·6 선행, 15분 이전 상대 역할 솔로킬 통계를 표본 크기와 함께 해석합니다. Team Summary와 Matchup Detail에서 상세 내용을 확인할 수 있습니다.
- 상대 챔피언 초상화를 눌러 QWER Skill Detail을 열고 원래 화면으로 돌아갈 수 있습니다. 173개 챔피언과 692개 스킬의 한국어 설명·아이콘·대기시간을 로컬에서 제공합니다.
- 충전형, 토글, 자원 조건, 지속 효과 등 특수 스킬은 메커니즘에 맞춰 표시하며, 스킬 화면은 네트워크를 요청하지 않습니다.
- 정적 통계 데이터 업데이트, 설정·창 크기/위치·항상 위 표시 저장을 제공합니다.
- 로그와 crash diagnostics로 오류 확인을 돕습니다.
- 관리자 권한이 필요 없는 installer와 Runtime 별도 설치가 필요 없는 portable ZIP을 제공합니다.

## 알려진 제한

- 실제 역할별 Skill Order 통계는 아직 제공하지 않습니다.
- 일부 특수 스킬 수치는 정확한 정적 정보를 확보할 수 없어 “정보 없음” 또는 메커니즘 설명으로 표시됩니다. 변신·무기별 모든 파생 스킬을 포함하지 않습니다.
- 현재 게임 패치를 연결 정보에서 확인할 수 없으면 Unknown/패치 일치 여부 확인 불가로 표시됩니다.
- 실행 파일과 installer는 서명되지 않았으며 Windows SmartScreen 경고가 표시될 수 있습니다. 보안 기능을 끄거나 우회하지 마세요.
- installer는 낮은 버전 설치를 기술적으로 차단하지 않습니다. 이전 버전 재설치를 피하세요.
- 앱 자동 업데이트는 제공하지 않습니다. 통계 데이터 업데이트와 앱 버전은 독립입니다.

기본/production 통계는 2026-10-04 확인 기준 KR Ranked Solo/Duo 16.17, revision 1788854099077이며, 스킬 데이터는 Riot Data Dragon 16.17.1입니다. 최신 게임 패치와 일치한다고 보장하지 않습니다. 새로운 통계 데이터는 별도 검증 후 배포합니다.

## 설치 및 업그레이드

1. 실행 중인 앱을 종료합니다.
2. `LoLMatchInfo-1.0.0-win-x64-setup.exe`를 실행합니다.
3. 기존 설정·로그·내려받은 통계는 보존됩니다. Portable은 `LoLMatchInfo-1.0.0-win-x64-portable.zip` 전체를 풀고 `LoLMatchInfo.exe`를 실행합니다.

문제 보고에는 앱/Windows 버전, 시각, 재현 절차를 포함하세요. 로그 위치는 `%LocalAppData%\LoLMatchInfo\Logs`입니다. 파일을 공유하기 전에 개인정보 유무를 확인하세요. Riot Games 공식 제품이 아닙니다.
